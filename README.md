# Personal website and Language Games

A child-friendly website presenting a speech and language therapist, with a growing collection of interactive browser games about language and learning.

## Overview

This project is the showcase website of a freelance speech and language therapist for children. Beyond the presentation pages, the site is designed to host a series of educational minigames about language and learning. The games are meant for children, to be played at home together with their parents, and combine simple mechanics with immediate, encouraging feedback.


## Features
- **Presentation website:** Home page with hero, introduction, about section, areas of intervention, how the therapy works, a section for parents, and contacts.
- **Areas of intervention:** Language disorders, learning disorders (reading, writing, calculation), dysphagia and atypical swallowing, and voice disorders (dysphonia), in both childhood and adulthood.
- **Educational minigames:** A collection of simple games on language and learning, for example matching words and images, completing words, and memory games.
- **Responsive interface:** The layout adapts to smaller screens, with a collapsible menu on mobile.

## Technologies
- HTML5
- CSS3 — styling, layout, and responsive design
- JavaScript — interactions and, later on, the game logic

## Getting Started

The website runs directly in a web browser and does not require any installation or additional dependencies.

1. Clone or download this repository.
2. Open `index.html` in your browser.
